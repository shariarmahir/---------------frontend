Animated icons from lordicon.com (free "Wired Lineal" set, Lottie JSON), one file per icon.
Use them with <CardIcon name="<file name without .json>" fallback="<material symbol>" />
(components/ui/card-icon.tsx), which draws every icon in the landing page's one look.
The free licence requires the "Animated icons by Lordicon" credit in the site footer.
